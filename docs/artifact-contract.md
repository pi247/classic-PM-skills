# Portable document and context contract

Skill-facing SoT is markdown. Pi247 dual-writes the same shapes to reserved Knowledge Hub pages where applicable.

## Context files

| File | Pi247 reserved slug | Role |
| --- | --- | --- |
| `ORG_CONTEXT.md` | `org-context` (Portfolio Hub) | Org identity, governance, vocabulary, standards |
| `PROJECT_CONTEXT.md` | `project-context` (project space) | Project identity, boundaries, success, people, document index |
| `DECISIONS.md` | Decision Log index; KH **Decision** pages = structured SoT | Chronological decision index |

Minimum sections: see `examples/context/`.
