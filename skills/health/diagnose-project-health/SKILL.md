# Diagnose project health

## Inputs

Read context + charter, scope, WBS, risk register, Decision Log, and recent status if present.

## Output

A short diagnosis: what is healthy, what is at risk, open assumptions, recommended next skill (`recover-project`, a draft-* revision, or `/stress-test`).
